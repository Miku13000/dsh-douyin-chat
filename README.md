# 抖音群聊聊天（dsh-douyin-chat）

> ⚠️ **风险提示**：本项目通过**非官方接口**操作抖音网页版，可能被平台判定为违规，**导致账号被限流或封禁**。使用即表示你知悉并自行承担全部后果。请勿用于营销、批量操作等滥用场景。

一个 DSH（DeepSeek Harness）插件：把抖音的群聊 / 私信 / 评论区接到你的 AI 助手上，让它在群里自然接话、私信里陪你聊天、还能看懂对方发的表情包。

## 功能

| 模块 | 说明 |
|---|---|
| **群聊自动回** | 被 @ 或被叫名字时回话；也能设成"自然插话"（有冷却） |
| **私信自动回** | 好友发来新消息自动回 |
| **@ 人** | 群里能真正 @ 到人（先打字过滤弹层，再点选，名字变蓝）；没人指定时自己挑一个 |
| **看懂表情包** | 对方发图 → 视觉识别成一句中文（如"Q版蓝发女仆双手比心"），再据此接话 |
| **表情包发送** | 复用已有表情库（QQ 同步 / dsh-mee / 自建目录），按情绪标签随机发 |
| **私聊分享** | 随机挑视频以**卡片**发给好友；**群聊一律不发** |
| **评论区 @** | 在视频下发评论并 @ 人（需要本机另装评论区执行器，见下） |
| **会话管理** | 私聊可直接加；**群聊要你确认**才加入监听 |
| **人设 / 记忆** | 两条通道：接共享人设，或用面板里自己写的 |
| **时段控制** | 空闲多说、高峰少说；也能只在清闲时段说话 |

## 省 token 的几个设计

- 系统提示按场景分级：**群聊 ~1260 token / 私聊 ~2000 token**（默认不再是每条 4000+）
- 同一触发消息 **30 分钟内不重复调模型**
- 超短消息（一个表情、一个字）且没点名 → 不调模型
- 上下文只带最近 4 条
- 图片识别结果缓存，同一张图只识别一次

## 安装

1. 装好 [DSH](https://github.com/deepseek-ai/dsh)
2. 把本目录放到任意位置，一条命令装插件：

```bash
dsh plugin add --profile web link:.
```

> 桌面版（Electron 托管 profile）CLI 会拒绝，改成在应用里「设置 → 插件 → 添加本地插件 → 选本目录」。

3. 重启 DSH，左侧栏出现**抖音群聊聊天**
4. 图标可换：把自己的图片存成 `~/.dsh/fish/icon.png`

## 首次使用

1. 面板 → **登录** → 浏览器窗口里扫码
2. 点 **检查环境**，四项全绿
3. **设置**里打开「群聊自动回」「私信自动回」
4. 想自动分享视频：**调整计划**里开启（默认 09:00 / 20:00，每次 3 条）

## 可选依赖（不装也能用）

| 能力 | 需要什么 |
|---|---|
| **看懂图片/表情包** | [modlens](https://www.npmjs.com/package/@liustack/modlens) + Antigravity CLI（`irm https://antigravity.google/cli/install.ps1 \| iex`，然后跑一次 `agy` 登录） |
| **评论区 @ 人** | 本机装一个能跑 `comment-mention-ui.mjs` 的执行器，用 `DOUYIN_SCROLL_DIR` 指向它 |
| **通知读取** | 一个提供 `douyin_notices` 工具的 MCP server，用 `DOUYIN_MCP` 指向它 |
| **共享人设/记忆** | `qq-bridge` + `mnemon`；没有就用面板里「自己写」 |

相关环境变量：

```bash
DOUYIN_SCROLL_DIR   # 评论区执行器目录
DOUYIN_MCP          # MCP server 路径
MODLENS_MAIN        # modlens 的 dist/main.js
AGY_BIN             # agy 可执行文件
FISH_SELF_NICK      # 你自己的抖音昵称（默认"小鲸鱼"）
```

## 数据存在哪

全部在本机 `~/.dsh/fish/`：

```
config.json      偏好（不含密码，只有昵称/开关）
accounts/        抖音 Cookie
stats.json       今天的动作计数
traffic.json     每小时消息量（判断忙闲）
guard-state.json 评论/分享的限速状态
vision-cache.json 图片识别缓存
persona.md       你自己写的人设
memory.md        你自己写的记忆
stickers/        自建表情目录
icon.png         侧边栏图标（可选）
```

## 常见问题

**面板显示「服务离线」**
后台服务（3110）没起来。面板里有「重启后台服务」；也可以手动 `node bin/service.mjs` 看报错。

**读消息很慢**
默认每次读都新开无头浏览器（约 10 秒）。设置里开「常驻浏览器」可降到 1~2 秒，代价是常驻一个 Chrome 进程。

**它重复说同一句话**
已内置三道防护（锚点推进 / 触发去重 / 内容去重）。如果还发生，把 `~/.dsh/fish/watch.log` 里那几行发出来。

**能自动回关粉丝吗**
不行。抖音网页版对无头浏览器不渲染粉丝列表（实测结论），目前没有可靠实现。
