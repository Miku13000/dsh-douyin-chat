# 抖音群聊聊天（dsh-douyin-chat）

> ⚠️ **风险提示**：本项目通过**非官方接口**操作抖音网页版，可能被平台判定为违规，**导致账号被限流或封禁**。使用即表示你知悉并自行承担全部后果。请勿用于营销、批量操作等滥用场景。

一个 DSH（DeepSeek Harness）插件：把抖音的群聊 / 私信 / 评论区接到你的 AI 助手上，让它在群里自然地接话、私信里陪你聊天。

## 它能做什么

| 模块 | 说明 |
|---|---|
| **群聊自动回** | 被 @ 或被叫名字时回话；也可以设成"自然插话"（有冷却） |
| **私信自动回** | 好友发来新消息自动回，不需要你盯着 |
| **表情包** | 复用你已有的表情库（QQ 同步 / dsh-meme / 自建目录），按情绪标签随机发 |
| **随机分享（仅私聊）** | 随机挑一条视频，以**分享卡片**发给指定好友；**群聊一律不发** |
| **评论** | 读取视频评论（网络层截获官方接口） |
| **人设 / 记忆** | 两条通道：接 QQ 那套共享人设，或用面板里自己写的 |
| **时段控制** | 空闲时多说、高峰时少说；或只在清闲时段说话 |

## 安装

1. 先装好 [DSH](https://github.com/deepseek-ai/dsh)（桌面版或 web 版）
2. 把本目录放到任意位置，然后在 DSH 里安装这个本地插件：

```bash
dsh plugin add link:/path/to/dsh-douyin-chat
```

> 桌面版（Electron）的 profile 由应用托管，直接在应用内「插件」页选择本目录安装即可。

3. 重启 DSH，左侧栏会出现**抖音群聊聊天**（图标可以在 `~/.dsh/fish/icon.png` 换成自己的）

## 首次使用

1. 打开面板 → **开始使用 → 登录**，会启动一个浏览器窗口，扫码登录抖音
2. 点 **检查环境**，四项都绿了就可以用
3. 在 **设置** 里打开「群聊自动回」「私信自动回」
4. 想让它自动分享视频：**调整计划** 里开启自动计划（默认 09:00 / 20:00，每次 3 条）

登录态存在 `~/.dsh/fish/accounts/`，不会上传任何地方。

## 数据存在哪

全部在本机 `~/.dsh/fish/`：

```
config.json      偏好（不含密码，只有昵称/开关）
accounts/        抖音 Cookie
stats.json       今天的动作计数
traffic.json     每小时消息量（用来判断忙闲）
persona.md       你自己写的人设
memory.md        你自己写的记忆
stickers/        自建表情目录
icon.png         侧边栏图标（可选）
```

## 依赖

- Node.js 22+
- 本机装有 Chrome / Edge（自动探测，也可在面板里选）
- 可选：`qq-bridge` + `mnemon`（想复用 QQ 那套人设和记忆时才需要；没有就在面板里用「自己写」）

## 常见问题

**面板显示「服务离线」**
后台服务（端口 3110）没起来。面板里有「重启后台服务」按钮；也可以手动 `node bin/service.mjs` 看报错。

**读消息很慢**
默认每次读都新开一个无头浏览器（约 10 秒）。在设置里打开「常驻浏览器」可以降到 1~2 秒，代价是常驻一个 Chrome 进程。

**分享失败**
卡片分享依赖网页端的分享面板，偶尔会失败。服务会自动重试 3 次；如果一直失败，多半是账号被风控了，建议停几天。

**能自动回关粉丝吗**
不行。抖音网页版对无头浏览器不渲染粉丝列表（这是实测结论），目前没有可靠实现。
